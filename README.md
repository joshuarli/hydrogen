# Hydrogen (moved)

Hydrogen, the Nanos fork that runs Chromium's multiprocess sandbox in one
microVM, now lives in [bctl](https://github.com/joshuarli/bctl) under
`kernel/`, with this repository's full history. Its documentation is in
`docs/kernel/` there, starting with
[kernel development](https://github.com/joshuarli/bctl/blob/main/docs/kernel/development.md).
Open work is in bctl's `TODO.md`.

This repository is archived.
